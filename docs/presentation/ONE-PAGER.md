# VibeFlow — One‑Pager

**AI‑orchestrated software delivery, with governance and quality built in.**
A Claude Code plugin that runs your full SDLC through multi‑AI consensus
and truth‑validated requirements. v2.18.0 · 100% local · feature‑complete.

---

### The problem
AI writes code fast — but doesn't guarantee you built the *right* thing,
*safely*. Ambiguous requirements become defects, a single model is
confidently wrong with no audit trail, and quality checks arrive too late
to be cheap. The bottleneck has moved from *writing* code to *trusting* it.

### The solution
VibeFlow governs all **seven SDLC phases** (Requirements → Deployment) as
one auditable loop, on four principles:

- **Truth‑driven** — requirements are scored for testability; untestable
  specs *block* development.
- **Consensus‑based** — critical artifacts are reviewed by **multiple AIs**
  (Claude + ChatGPT + Gemini) with quorum, iterative convergence, and
  explicit human escalation — never a silent pass.
- **Quality‑gated** — automated, risk‑proportional gates at every phase
  boundary (Healthcare ≥ 95, Financial ≥ 90, E‑commerce ≥ 85, General ≥ 80).
- **Self‑improving** — learns from its own review history and auto‑tunes
  within strict bounds, **auto‑reverting** anything that regresses.

### Why it's different
| | Single‑AI tools | VibeFlow |
|---|---|---|
| Review | One opinion | Multi‑AI consensus + audit trail |
| Requirements | As‑is | Scored & gated |
| Scope | Code gen | Full 7‑phase SDLC |
| Improvement | Static | Self‑tuning with auto‑revert |
| Data | Cloud/SaaS | 100% local; state in your Git |

### Proof
**v2.18.0**, 30 sprints, **2,943 automated tests across 30 layers**, green
every release. 40+ skills · 5 analysis engines · 9 AI sub‑agents.
File‑backed, event‑sourced, Git‑versioned state — zero‑ops, fully
auditable. Your code never leaves your environment.

### Business outcomes
Fewer escaped defects (caught at the PRD) · faster, defensible release
decisions · lower review fatigue · audit‑ready by default · compounding
value as it self‑tunes.
