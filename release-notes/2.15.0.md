# VibeFlow v2.15.0 — Template-Route Autonomy (Propose-Only)

**Sprint 27** (backlog B1). The learning loop's "act" stage handled
config changes autonomously since v2.12.0, but the **template lane** was
manual: a `recurring-suggestion-theme` finding (a systemic PRD/ADR/
test-strategy gap) only produced a "run `/vibeflow:consensus-specialist`
by hand" recommendation. v2.15.0 makes it **auto-fork the specialist** —
propose-only.

## Auto-fork, opt-in, propose-only

New `learningApply.autoForkSpecialist` (default **off**). When on, a
recurring-theme finding makes `learning-apply`:

1. write a **learning-fork brief** (theme + affected artifact + seenCount
   + rationale) to `.vibeflow/state/patches/learning-fork-<ts>/brief.md`;
2. **fork the matching phase specialist** (prd-rewriter, adr-author, …)
   pointing it at the brief + artifact;
3. the specialist emits its usual **diff-first patch** into the fork dir
   — never writing the artifact directly.

`learning-apply` **never applies the patch.** It stops after forking; the
operator confirms via `/vibeflow:apply-arbiter-patch`. Default off ⇒
template-route stays recommend-only (Sprint 22-C) for anyone who doesn't
opt in.

## Why templates stay confirm-only

Deliberately stricter than config's bounded auto-apply (Sprint 23–24). A
config tune is small, schema-bounded, and **auto-reverted** if the next
consensus round regresses. A template/PRD/ADR rewrite is large, unbounded,
and not mechanically revertible against an agreement curve — so it stays
human-confirmed. Auto-fork removes the manual *dispatch* toil; it does not
remove human *review* of the rewrite.

## The bridge

The six phase-specialist agents are normally consensus-session-driven
(they read `verdict.json` + reviewer suggestions). They now also accept a
**learning-fork brief** as an equivalent trigger — documented once in
`agents/_shared/learning-fork-brief.md`, referenced by each agent. The
diff-first / never-write-source contract is unchanged.

## Configuration

```jsonc
{ "learningApply": { "autoForkSpecialist": false } }
```

See `docs/TEMPLATE-AUTONOMY.md`.

## Upgrade

```
/plugin uninstall vibeflow@vibeflow
/plugin install vibeflow@vibeflow
/reload-plugins
```

No migration; `autoForkSpecialist` is off by default.
