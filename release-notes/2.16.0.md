# VibeFlow v2.16.0 — Cross-Project Meta-Learning (Read-Only)

**Sprint 28** (backlog B2). The meta-learning loop (v2.12.0) learns which
config tunes stick — but per project. A tune that reliably holds in five
repos is re-discovered (and re-reverted on the bad ones) in the sixth.
v2.16.0 lets a multi-project operator share that signal across repos —
**opt-in, privacy-safe, read-only**.

## Three guarantees

1. **Opt-in, default off.** `globalLearning.enabled` is `false`. Nothing
   leaves a project unless turned on.
2. **Privacy-safe.** Only `{key, outcome, phase, projectHash}` is mirrored
   to the shared store — **no code, content, artifact/file names, or theme
   text.** `projectHash` is a one-way sha256 of the project id (first 12
   hex chars): distinct repos are *counted*, never *identified*.
3. **Read-only recommendation.** A new project *reads* the cross-project
   signal as a **recommendation** in the learning report. It **never**
   auto-allowlists or auto-applies — one repo's record can't change
   another's behaviour.

## How it works

- **Store (S28-A/B).** New `globalLearning.enabled` config + `vf_global_dir`
  / `vf_project_hash` helpers. When enabled, `consensus-aggregator.sh`
  (auto-revert / auto-apply-held) and `learning-apply` (auto-apply) mirror
  the privacy-safe outcome row to
  `$(vf_global_dir)/global-learning.jsonl` (default `~/.vibeflow/`,
  overridable via `VIBEFLOW_GLOBAL_DIR`).
- **Recommendation (S28-C).** `learning-loop-engine`'s consensus-history
  mode gains `cross-project-signal`: for a key seen in ≥ 3 distinct
  projects, hold-rate ≥ 0.7 ⇒ "consider allowlisting (held in N/M
  projects)", ≤ 0.3 ⇒ "avoid (reverted in N/M projects)". Advisory only.
  `patternCatalogVersion` → 4.

## Configuration

```jsonc
{ "globalLearning": { "enabled": false } }
```

Wipe anytime: `rm ~/.vibeflow/global-learning.jsonl`. No server, no sync,
no network — a single append-only local file you control. See
`docs/CROSS-PROJECT-LEARNING.md`.

## Upgrade

```
/plugin uninstall vibeflow@vibeflow
/plugin install vibeflow@vibeflow
/reload-plugins
```

No migration; `globalLearning` is off by default.
