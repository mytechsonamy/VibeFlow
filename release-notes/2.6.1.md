# VibeFlow v2.6.1 — Plan Persistence Hook + SPRINT-14..18 Backfill

Process-gap patch. CLAUDE.md has asked for a
`docs/SPRINT-N.md` per sprint since Sprint 1, but the last one
on disk was `SPRINT-13.md` — Sprints 14-18 shipped with plans
only in the ephemeral `~/.claude/plans/<slug>.md` scratch file
that Claude Code wipes between sessions. This patch closes the
gap two ways.

## What's new

### Plan persistence hook

New `hooks/scripts/save-plan-doc.sh`, registered as a
PostToolUse hook on the `ExitPlanMode` matcher. Fires every
time a plan is approved and copies the approved markdown into
the repo at a deterministic path:

- Title matches `# Sprint NN — …` → `docs/SPRINT-NN.md`
- No sprint number → `docs/plans/<slug>-<YYYYMMDD>.md`

Fail-safes:

- Missing `jq` / empty stdin / missing plans dir → silent exit 0
  (the hook never blocks `ExitPlanMode`)
- Non-VibeFlow project (no `vibeflow.config.json` at cwd) →
  silent exit 0, so the hook doesn't pollute unrelated Claude
  Code sessions
- Env bypass: `VF_SKIP_PLAN_SAVE=1` exits 0 without writing

Advisory line goes to stderr on every fire:

```
VibeFlow: plan saved to docs/SPRINT-NN.md
```

### SPRINT-14..18 backfill

Five new docs reconstructed from:
- the corresponding `release-notes/*.md`
- `CHANGELOG.md` entries
- `git log feature/sprintNN-*` branches

Each is 100-200 lines: Context, Tickets shipped (with commit
SHAs), Outcome, Known follow-ups where relevant, and a "See
also" block pointing at the release notes, CHANGELOG, and git
tag.

Sprint 17's doc rolls up the four v2.5.1 → v2.5.4 patches as
"Known follow-ups" so the full Sprint-17 arc (including the
critical `.mcp.json` `${CLAUDE_PLUGIN_ROOT}` fix and the
auto-record consensus polish) is captured in one place.

### ROADMAP.md appendix

A short "Completed Sprints Appendix" table linking Sprints
8-18 with ship dates and themes. The per-sprint narrative rows
above stop at Sprint 7; rather than rewriting them all, the
appendix covers 8-18 with a one-line-each index.

## FlowBridge_TR impact

After upgrade, every `/plan` session in a VibeFlow project
auto-saves its approved plan into `docs/`. The very next plan
landed by FlowBridge_TR operators will materialise as
`docs/SPRINT-NN.md` without any extra step.

## Upgrade

```
/plugin uninstall vibeflow@vibeflow
/plugin install vibeflow@vibeflow
/reload-plugins
```

No config migration needed. The hook activates automatically
and is scoped to VibeFlow projects only.
