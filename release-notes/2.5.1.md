# VibeFlow v2.5.1 — `/vibeflow:advance` skill

Post-Sprint-17 polish. Fixes a long-standing documentation /
implementation gap: `/vibeflow:advance` was listed in CLAUDE.md's
"Key Commands" since v1.0 but the skill didn't exist — Claude Code
had nothing to dispatch when operators typed it. This release
ships the skill.

## What's new

### `/vibeflow:advance <TARGET_PHASE> [humanOverrideNote="..."]`

Thin wrapper around `sdlc_advance_phase` MCP tool:

```
/vibeflow:advance DESIGN
/vibeflow:advance DESIGN humanOverrideNote="YOS tier resolved offline with Legal"
/vibeflow:advance design               # case-insensitive
```

Under the hood:

1. Reads `projectId` from `vibeflow.config.json`
2. Uppercases the target phase
3. Parses optional `humanOverrideNote="..."` from $ARGUMENTS
4. Calls `mcp__sdlc-engine__sdlc_advance_phase`
5. Surfaces success ("Advanced REQUIREMENTS → DESIGN. Revision
   now 5.") or the validator's failure list with remediation
   suggestions:
   - `consensus.<phase>.approved` missing →
     `/vibeflow:consensus-orchestrator <primary-report>`
   - `last consensus is NEEDS_REVISION` →
     `/vibeflow:consensus-arbiter <sid>` or
     `/vibeflow:consensus-specialist <sid>`
   - `testability.score>=60` / `coverage.met` → run the
     relevant analyzer

### Guardrails

- **No `force: true` from the skill.** Forcing a phase advance
  bypasses every exit-criterion check. That has to go through
  direct MCP tool invocation so the audit trail shows the
  operator typed it out.
- **humanOverrideNote only matters under HUMAN_APPROVAL_REQUIRED.**
  Passing it on a fully-APPROVED advance is harmless but
  omitted for cleaner audit trails.

## Why a patch release

Sprint 17 shipped the MCP-tool support for `humanOverrideNote`
and the HUMAN_APPROVAL_REQUIRED path on 2026-04-20. The user-facing
entry point was still documented-but-missing. A fresh VibeFlow
upgrade picks this up automatically; no config migration needed.

## Upgrade

```
/plugin uninstall vibeflow@vibeflow
/plugin install vibeflow@vibeflow
/reload-plugins
```

or via GitHub release tarball: pull
`vibeflow-plugin-2.5.1.tar.gz` and install.
