# VibeFlow v2.20.2 — reviewer rationale no longer lost to prose-wrapped JSON

A patch release for a structural bug surfaced across both FlowBridge_TR and
AntOS: **codex kept returning `NEEDS_REVISION` with no rationale**, so the
specialist→apply loop ran blind and consensus never converged (agreement
stuck at 0.50 no matter how many times the PRD was rewritten).

## Root cause

`append_cli_verdict` (in `consensus-run.sh` and the `consensus-orchestrator`
prose) parsed each reviewer's verdict by running `jq 'fromjson'` over the
CLI's **entire** stdout. But codex/gemini routinely wrap their JSON verdict
in prose or a Markdown ```` ```json ```` fence:

```
Here is my review:

​```json
{"verdict":"NEEDS_REVISION","criticalIssues":[…],"suggestions":[…]}
​```
```

A whole-output `fromjson` on that **fails** → the parser fell through to a
keyword grep that recovered only the word `NEEDS_REVISION`, throwing away the
structured `criticalIssues` + `suggestions`. The reviewer's actual findings
never reached the jsonl, reviewer-memory, or the specialist — so the
specialist had nothing concrete to fix, and the panel could never agree.

## Fix

New `vf_extract_json` helper unwraps the verdict JSON before parsing:

1. try the whole output (fast path: pure JSON),
2. strip Markdown code-fence lines and retry,
3. grab the first-`{` … last-`}` span and retry.

The extracted object feeds every field (verdict, `criticalIssues`,
`criticalItems`, `suggestions`). So a fenced/prose-wrapped dissent now lands
its full rationale — the specialist gets actionable findings and the loop can
actually converge.

- Pure-prose replies (no JSON at all) still fall back to keyword-grep
  classification — unchanged.
- Pure-JSON replies — unchanged.
- Fixed in both the headless runner and the interactive 3-AI orchestrator.

Pinned by `tests/integration/sprint-31.sh [S31-C]`: a runtime probe feeds a
fenced-JSON-in-prose codex reply and asserts `suggestions` + `criticalItems`
are captured (would be empty pre-fix).

## Note on the "single silent dissenter" fragility

This release fixes the *parse* half of the convergence trap. If a reviewer
genuinely emits a verdict with **no** structured rationale, the existing
escape valves still apply: run the interactive `/vibeflow:consensus-orchestrator`
(adds claude-reviewer), or settle the phase with an explicit operator
override (`sdlc_advance_phase force:true` + `humanOverrideNote`). With the
parse fixed, most codex dissents now carry their findings, so blind loops
should be far rarer.
