# VibeFlow v2.43.0 — catch a "skinless" UI in DEVELOPMENT

A live ANTOS render-check found something worse than a divergent design: the
dashboard had been built with the right DOM, content binding, a11y, and even the
design's class names — but **no CSS at all**. No stylesheet, no Tailwind, no
CSS-in-JS, `design-tokens.json` never imported. It rendered as bare default HTML,
nothing like the mockup.

The painful part: **nothing caught it.** It compiled, lint/typecheck/tests
passed, and a diff reads clean — because a *missing* stylesheet is an **absence**,
invisible to `quality-gates` and to `code.reviewed` on the diff. The design was
specified (a token-driven mockup) and then simply never implemented.

## What's new

`hooks/scripts/ui-styling-check.sh` statically classifies a web UI:

- **`skinless`** — components use `className`/`class` but there's **no** stylesheet
  import, Tailwind/PostCSS config, CSS-in-JS, linked stylesheet, or design-token
  consumption anywhere.
- **`styled`** — any one of those styling layers is present.
- **`no-ui`** — no web UI (e.g. a backend-only repo) → quiet.

`phase-runner`'s DEVELOPMENT walk runs it on the increment and surfaces a
`skinless` result **prominently**:

> ⚠ the UI uses className but applies no stylesheet/tokens — the design
> (mockup + design-tokens.json) was specified but never implemented. Implement
> the styling before TESTING.

So a structure-only UI is caught **when it's written**, not three phases later.
The TESTING `frontend-render-check` runs the same check as an immediate hard
**BLOCKED** — nameable without even a browser. Surface-only in DEVELOPMENT (never
blocks/auto-runs; silent on a styled or backend-only repo).

Pinned by `tests/integration/sprint-55.sh` (static + runtime probes across no-ui /
skinless / styled[stylesheet / Tailwind / token] / backend-only).

## For ANTOS

Implementing the dashboard's styling (port `design-tokens.json` + the mockup CSS
into `apps/web`, align the class names) flips it from `skinless` to `styled` and
clears both this DEVELOPMENT flag and the `frontend-render-check` BLOCK.
